# 🌍 Smart Travel Planner — Maximum Places in Limited Time

## 📌 Project Overview

**Smart Travel Planner** is a Digital Algorithms and Applications (DAA) project that helps select the best combination of tourist places within a limited amount of available travel time.

The project demonstrates and compares three different algorithmic approaches:

1. **Backtracking**
2. **Branch and Bound**
3. **Dynamic Programming**

The main objective is to find a travel plan that provides the **maximum total value** while staying within the available time limit.

---

## 🎯 Problem Statement

Given a set of tourist places, where each place has a visiting time and a value, and a maximum available travel time, the system determines which combination of places should be selected to maximize the total value without exceeding the time limit.

---

## 🧠 Algorithms Used

### 1. Backtracking

Explores different combinations of places by making a choice and then backtracking when a combination becomes invalid or cannot improve the solution.

### 2. Branch and Bound

Uses a bounding technique to avoid exploring branches that cannot produce a better solution than the current best solution.

### 3. Dynamic Programming

Stores solutions to smaller subproblems and reuses them to efficiently find the optimal solution.

---

## 📊 Project Objective

The project aims to:

* Find an optimal combination of tourist places.
* Demonstrate how different algorithms solve the same problem.
* Visualize or represent the working of the algorithms.
* Compare the results and performance of the algorithms.
* Understand the differences between Backtracking, Branch and Bound, and Dynamic Programming.
